# Building from source

## Requirements

- A Mac with a recent Xcode (tested with Xcode 26) and an Apple ID for signing.
- [Homebrew](https://brew.sh) for the build tools. On Apple silicon use the native Homebrew in `/opt/homebrew`.
- Build tools for libsignal:
  ```bash
  brew install cmake protobuf cocoapods
  curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
  source "$HOME/.cargo/env"
  ```
- `xcode-select -p` must point to Xcode (`sudo xcode-select -s /Applications/Xcode.app/Contents/Developer` if it shows CommandLineTools).

Use a folder path without spaces.

## Build

```bash
git clone https://github.com/popoviclazar/ghostecc.git
cd ghostecc
./scripts/setup_mac.sh          # downloads libsignal at the pinned commit, builds it and runs pod install
open GhostECC.xcworkspace       # always the workspace, never GhostECC.xcodeproj
```

Building libsignal takes 15–40 minutes the first time. In Xcode, choose your team under Signing & Capabilities and run.

If Xcode reports `Framework 'LibSignalClient' not found`, build once from the command line and run again:

```bash
xcodebuild -workspace GhostECC.xcworkspace -scheme GhostECC -destination 'generic/platform=iOS Simulator' build
```

## Tests

```bash
xcodebuild test -workspace GhostECC.xcworkspace -scheme GhostECC -destination 'platform=iOS Simulator,name=iPhone 17'
(cd server && npm test)                       # relay server, Node.js 20+
python3 server/test/crosscheck.py             # independent client against the relay (pip install cryptography)
python3 scripts/validate_static.py            # project, localization and protocol consistency
```

In the simulator, enable Features → Face ID → Enrolled, otherwise the app lock cannot be opened.

## Your own build or fork

- **Relay address and links:** `GhostECC/Core/AppConfig.swift`. To run a relay, see [server/README.md](../server/README.md).
- **Bundle ID and signing:** the Xcode project is generated by `scripts/generate_project.py` (needs Pillow); change `PRODUCT_BUNDLE_IDENTIFIER` there, regenerate, then run `pod install`. Push notifications need your own APNs key and the relay's `--topic` set to your bundle ID.
- **Text:** Serbian text in the code is the localization key. After changing UI text run `python3 scripts/l10n.py`; it checks that every string has an English translation in `GhostECC/Localization/translations-en.json` and writes the `.strings` files.
- **Local relay for simulators:** `bash scripts/dev_local.sh` starts the relay with HTTPS on `https://localhost:8443` (Caddy with a local certificate added to booted simulators); `--tunnel` gives a temporary public address for a real device. Point `AppConfig.defaultServer` at it while testing.
